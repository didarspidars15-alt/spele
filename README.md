# Bolt Food Delivery Pro Max

Šī ir 2. tēmas noslēguma spēle. Tās mērķis ir palīdzēt kurjeram atrast piegādes vietu Āgenskalnā.

## Projekta struktūra
- `index.html` — spēles galvenā lapa
- `25.html` — darba variants
- `atteli/` — varoņa attēls
- `skanas/` — skaņas fails

## Kā atvērt
Atver failu `index.html` pārlūkā no projekta mapes.

## Ko satver lapa
- vienkāršs un skaidrs dizains
- centrēts spēles laukums
- varonis, skaņa un punktu skaitītājs
- poga, kas palielina punktus pēc katra klikšķa
