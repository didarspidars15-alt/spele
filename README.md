# Bolt Food Delivery Pro Max

Spēles mērķis: palīdzēt kurjeram atrast piegādes vietu Āgenskalnā. Nospied pogu, lai par katru klikšķi iegūtu vienu punktu. Spēles skaņu var atskaņot ar audio vadības joslu.

Atver `index.html` pārlūkā. Lejupielādē visu projektu un saglabā mapju struktūru, lai attēls mapē `atteli` un skaņa mapē `skanas` būtu pieejami.
